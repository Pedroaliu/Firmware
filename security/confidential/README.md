# Confidential LPAR

Confidential computing is a long-term Jixia requirement, not a late plug-in.

A confidential LPAR may distrust ArchHV, Luban, BMC, the cloud administrator, peer partitions, and DMA devices. Its future contract includes:

- private/shared page states;
- protected register state;
- per-LPID memory encryption and integrity;
- anti-replay;
- protected interrupt and IOMMU context;
- measurement and remote attestation;
- debug lifecycle enforcement;
- secure migration.

Use the technical name `Confidential LPAR` until a deliberate canonical cultural name is selected.
