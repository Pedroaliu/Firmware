# Taiyi / 太乙

Taiyi performs recovery actions selected from policy and Bianque diagnosis.

Planned actions include retry, alternate path, service restart, vCPU/LPAR reset, page retirement, device reset/reassignment, topology degradation, checkpoint restore, firmware/configuration recovery, failover, and migration.

Recovery must be executable from a state that does not depend on the failed target remaining trustworthy.
